# 多图预览 Windows系统修复工具 Windows Repair Toolbox v3.0.4.7 - 剑二十七

《Windows Repair Toolbox》（WRT）是一个便捷的工具包，能帮助你修复Windows系统，并使整个过程更快速、简易、一致。

基本特性：

多功能集成：你可以用它在运行时下载并运行世界上最好的免费软件，来诊断和解决各种Windows问题。除了三个例外，所有包含在工具箱中的程序都是便携式的。工具按功能分类，程序会自动为你正在使用的Windows版本下载正确的版本。

更新管理：在你检查普通所需工具时，它还会帮你更新它们。

一键下载：有能力用一键下载所有工具（并保持它们更新），以便你在离线电脑上使用Toolbox，或者仅仅提前下载所有工具。

无人值守模式：在无人值守模式下，选择几个工具，连续运行，执行恶意软件清除、系统清理和修复。当过程完成时，系统还可以发送包含日志的邮件。

机器信息：显示要修复的计算机的相关信息，如CPU温度、名称和使用百分比、安装在系统上的RAM量和使用率、硬盘型号、容量、基础健康检查、系统分区剩余的空闲空间、Windows版本和安装日期、系统启动时间等。

第三方功能：它提供了易于运行的最常用的chkdsk、sfc和DISM命令的功能，还有用于Sysinternals Suite的GUI，并可以访问 Antivirus Removal Tool。

支持你添加自己喜爱的工具到程序中，自定义程序图标和标题栏文字。

提供质量保证测试功能，在修复完成后进行测试。

支持你在修复过程中保存笔记，方便你查看和管理。

还有一键式访问一些有用的Windows工具的功能。

使用WRT，任何情况下发生的任何事情，你都需要完全负责。在任何情况下使用此工具都没有保证。你需要保证有权使用这些第三方工具。

你需要在Windows 7到Windows 11的系统下方能使用此工具。
